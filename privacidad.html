Contacto para privacidad

Para consultas relacionadas con protección de datos y ejercicio de derechos, escribe a ismaeldbonline@gmail.com. El responsable del tratamiento es el titular identificado en esta página.

Finalidades y legitimación

Los datos de conexión que puedan gestionar los proveedores de alojamiento se utilizan para la prestación técnica y la seguridad del sitio, en la medida necesaria y según las bases jurídicas aplicables. La medición con Google Analytics 4 solo se activa tras el consentimiento del visitante (artículo 6.1.a del RGPD). Las consultas enviadas voluntariamente al correo de contacto se tratan para responderlas y atender las obligaciones que correspondan.

Datos introducidos en las calculadoras

Los cálculos se realizan en el navegador. Los valores introducidos en las calculadoras no se envían a un servidor propio de Cuentas Claras.

Atribución de campañas

Cuando una visita incluye parámetros UTM, la web puede conservarlos en el navegador solo después de que el usuario haya aceptado Analytics, para atribuir de forma estadística el origen de la visita. Si el usuario rechaza Analytics, el código propio elimina esa atribución almacenada.

Google Analytics 4

Cuentas Claras tiene configurado Google Analytics 4 para medir el uso de la web. El script de Analytics solo se carga después de que el usuario pulse “Aceptar Analytics”. Si se rechaza, no se carga GA4 desde el código de Cuentas Claras.

La web guarda localmente la preferencia de consentimiento para no volver a preguntar en cada página. La medición se utiliza para conocer qué páginas y calculadoras reciben visitas y mejorar el contenido.

Retirada del consentimiento

Puedes cambiar la elección de Analytics en cualquier momento desde el botón Configurar privacidad que aparece en el pie de las páginas. Al rechazar después de aceptar, la web deja de cargar Analytics en la siguiente visualización. Esto no elimina automáticamente datos ya tratados por proveedores externos.

Publicidad

Actualmente Cuentas Claras no incorpora Google AdSense ni otros anuncios. Si se añade publicidad en el futuro, esta política y la gestión del consentimiento deberán actualizarse antes de activarla.

Finalidades y derechos

Las estadísticas de Google Analytics se basan en el consentimiento del visitante. El alojamiento y las medidas técnicas de seguridad pueden implicar tratamientos de datos de conexión conforme a las bases jurídicas aplicables. Los visitantes pueden ejercer sus derechos de protección de datos y reclamar ante la Agencia Española de Protección de Datos (aepd.es).

Alojamiento y recursos externos

La web utiliza Vercel para alojamiento y Google Fonts para sus recursos tipográficos. Estos proveedores pueden recibir datos técnicos de conexión. La configuración concreta, los plazos de conservación y las transferencias internacionales deben comprobarse con las condiciones vigentes de cada proveedor.

Conservación y destinatarios

Los datos de consultas se conservarán durante el tiempo necesario para responder y atender las obligaciones legales aplicables. Las preferencias de consentimiento se almacenan en el navegador hasta que se cambian o eliminan. Los plazos concretos de conservación de registros técnicos y Analytics dependen de la configuración de cada proveedor y deben verificarse.

Para la prestación del servicio se utilizan Vercel como proveedor de alojamiento y servicios de Google para tipografías y, si se acepta, analítica. Su funcionamiento puede implicar tratamientos de datos técnicos y transferencias internacionales, sujetos a las condiciones y garantías aplicables.

Derechos de las personas interesadas

Puedes solicitar acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad cuando procedan, así como retirar el consentimiento. Para ello, escribe al correo de contacto indicado al comienzo de esta política. También puedes presentar reclamación ante la Agencia Española de Protección de Datos.

Servicios de terceros

Algunas páginas pueden contener enlaces externos, por ejemplo a fuentes oficiales. Al abandonar Cuentas Claras se aplican las políticas del sitio de destino.
